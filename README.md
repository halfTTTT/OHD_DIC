# Tomoshi 日中词典脚本

脚本文件：`jpcn_Tomoshi.js`。适用于 Online Dictionary Helper（ODH）的自定义词典接口。

## 显示内容

- 中文释义与词性。
- 假名读音与原站提供的重音标注，例如 `たべる [2] 中高型`。
- 日中双语例句，保留汉字上方的振假名。
- 词语发音，使用 Tomoshi 原站的音频地址，由 ODH 的发音按钮播放。

脚本先读取网站的公开索引，使用索引中指定的词条地址，避免同形词取到错误读音。例如“猫”会优先显示“ねこ”。查询结果按常用词优先，最多返回三个词条。索引或网页暂时不可用时会尝试直接词条地址，最终没有结果则返回空数组。

## 添加到 ODH

原版 ODH 的“自定义脚本”栏填写的是脚本的 HTTP(S) 链接，需要一个能直接返回 JavaScript 源码的地址。

1. 复制本仓库的脚本直链：`https://raw.githubusercontent.com/halfTTTT/OHD_DIC/main/jpcn_Tomoshi.js`。
2. 打开 ODH 选项，进入“脚本 / Scripts”。
3. 在“自定义脚本 / User-Defined Script”中填入该文件的 HTTP(S) 地址。如果已有其他脚本，按插件要求用英文逗号分隔。
4. 点击“保存并加载 / Save and Load”。
5. 在词典列表中选择“Tomoshi 日中词典”，保存设置后刷新要查词的网页。
6. 划选 `食べる`、`たべる`、`猫`、`ありがとう` 测试释义与发音。

脚本直链：`https://raw.githubusercontent.com/halfTTTT/OHD_DIC/main/jpcn_Tomoshi.js`。

如果使用的 ODH 分支提供“粘贴源码”编辑器，粘贴本文件的完整内容即可。标准 ODH 中只填写本地文件路径或粘贴源码不会完成加载。

## 可调整设置

- 例句数量：使用 ODH 的“最大例句数”设置，`0` 表示隐藏例句。数量按每条释义计算。
- 同形词条数：修改脚本构造函数中的 `this.maxentries = 3`。
- 默认例句数量：修改 `this.maxexample = 2`；ODH 加载的设置会覆盖该默认值。

## 范围与限制

- 本脚本查询词条写法或假名读音。请优先选择辞书形，例如选择 `食べる`；本版不实现网站搜索框的完整活用还原，因此 `食べた` 不保证查得到。
- 日语的读音按假名显示，并在原站提供时显示重音；不生成国际音标或罗马字。
- 释义、例句、读音均取自原站，不生成或补写原站没有的内容。不是每个词条都有全部项目。
- 发音来自网站已有的缓存音频，网站没有音频或网络请求失败时无法播放。浏览器需支持网站使用的 Ogg/Opus 格式。脚本不会在查词时自动播放声音。
- 本文件为一个类，符合 ODH 将整份源码作为类表达式加载的方式。不要在末尾添加 `new jpcn_Tomoshi()`、`module.exports` 或 `export`。

## 验证情况

使用从网站实际取得的页面和索引，在浏览器环境中核对类加载、中文义项、假名与重音、双语例句与振假名、同形词定位、零例句设置、无结果与网络失败、缓存及并发查询；另检查了内容转义与链接跟随范围。实际 ODH 扩展中的安装与按钮播放仍需在你的扩展环境中验证。
